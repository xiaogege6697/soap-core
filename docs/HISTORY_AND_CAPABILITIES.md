## 已能核实什么

| 候选用途 | 本轮证据 | 尚缺什么 |
|---|---|---|
| 基础时序研究分析 CLI | Python 禁用 site-packages 后，生成 80 行合成周期数据并完成默认分析，生成 CSV/SVG/报告 | 科学计算分支、真实任务使用、输入异常覆盖和独立交付版本还需按承诺核验；一次通路成功不等于通用预测有效 |
| 既有训练实验的基线比较 | 使用现有 phase_baseline 入口复算：静态 A 正常误报 20/20，B/C 为 0/20，受控干预检出均为 3/3；敏感性结果吻合原表 | 没有重新训练模型；不能把小样本观察当总体误报率，也不能复用当前阈值到其他模型/任务 |
| 类别几何研究材料 | 38 个预期 seed/condition 组合齐全，每份 280 行、7 层；数值有限，末段 layer_4 类中心有效秩约 3.895→1.115，与原表一致 | 复核的是既有 CSV 及统计，不证明采集过程无误或自然故障有效；不纳入默认诊断 |

## 能直接供后续接手使用的项目经验

- 数据列的语义会改变分析结果。训练步数作为时间标识处理；CSV 字段适配不能仅检查文件读得开。[原始故障与修复](v0.6_realish_benchmark.md)
- 合成数据的漂亮分类与真实场景的效果分开记录。研究方向因反例而收紧，是有效成果，不能只保留成功故事。[现行结论](CURRENT_STATUS.md)
- 单测或编译通过不能替代实际入口执行。v0.7.6 历史记录保留了脚本缺陷及端到端检查教训，本轮不冒充重新运行训练 smoke。[当前状态 §4](CURRENT_STATUS.md)
- 本机 8GB 的模型训练实验默认串行；早期并行 5 导致 swap 压力的建议已被后续实测否定。只在重新评估资源后改变执行方式。[当前状态 §4](CURRENT_STATUS.md)
- “选用方法 B”是实验方向；当前通用 `soap analyze` 没有接入 phase-aware 训练诊断参数，该能力使用独立模块入口。不要把路线图当已交付功能。

这些经验从项目报告提炼，不读取或合并任何 agent 的独立记忆、人格与相处经验。
